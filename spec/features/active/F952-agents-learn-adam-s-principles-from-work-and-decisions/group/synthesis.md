# Learning-system design

The discussion document is `/Users/overment/Downloads/limen-learning-system.html`. It recommends two source-linked files, three retrieval and learning skills, coordinator-led capture, and an opt-in audit timer after a manual pilot. Existing guidance keeps its authority. No system was installed and no product code changed.

## Selected ideas

- Keep confirmed principles in `spec/principles.md` and case evidence in one compact `spec/decisions.md`. Link current rule homes; do not move or duplicate their authority.
- Record a ruling in the coordinator turn that acts on it. Keep owner words, observations and agent interpretations distinct. A steer does not establish owner authorship.
- Use `discover-context`, `trace-decisions` and `learn-from-work`. Read only the sources that can change the current choice. Reuse the project guide before adding a context map.
- Name relations precisely: illustrates, constrains, shares a rule, depends on, replaces. Shared picture places do not prove dependency or owner rationale.
- A proposed weekly audit reads changed sources and missed captures. It reports and proposes; it never blocks work or declares policy. Proposed limits are one live audit per project, 20 minutes and five changed claims with overflow reported.
- Prove transfer using fresh questions, scope exclusions and counterexamples. Stored-note counts and successful jobs do not prove learning.

## Choices resolved

Start with one ledger rather than per-case files. Keep a separate principle register rather than leaving all reasons inside historical cases. Use skills first; automatic principle recall would be an explicit later hook change. Capture when the coordinator acts, not through keeper distillation or a mandatory finish lesson. A calendar timer is a real option; a landing-count advisory is not a timer. Retain existing review ownership rather than requiring a critic for every audit.

Reject automatic principle promotion, unreviewed transcript exports, a new root `AGENTS.md` that suppresses the inherited manual, and the picture as the durable store. Do not treat historical Alice report defects as current defects. Do not infer that a missing committed quality report proves no job ran.

## Open questions

- May an audit read named coordinator conversations? Recommend explicit permission and minimal reviewed excerpts.
- Enable the proposed audit after the manual pilot? Exact route and recurring spend need approval; never substitute a model on a limit.
- Which principles may cross projects? Recommend project-local scope and existing planning privacy until Adam authorizes sharing.
