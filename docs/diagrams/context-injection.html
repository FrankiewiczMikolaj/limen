Details

Loading

A coordinator loads the hooks through templates/limen-extension.ts. A job loads them through --extension flags from src/runtime/wrapper.ts (detached) or supervisor.ts (hosted).

System prompt, the Limen block

before_agent_start (hook/communication.ts) sets it, in this order. Each file is capped at 1000 lines.

  • Frame: templates/capability.md, every role, ≈70 tokens. No project file replaces it.
  • Private planning: only when the planning source is private.
  • Shop manual: templates/agents.md, coordinator only, only without a project AGENTS.md.
  • Register: communication.md, the text above the first “## Cue:”.
  • Search: the register's Search cue, only if jg is Jevgrep.
  • Vision: spec/vision.md, coordinator. Styleguide: .agents/limen/styleguide.md.
  • Board digest: NOW and NEXT of spec/build.md, coordinator, always last, so a board change breaks only the end of the prefix.

Hidden note (1), after the history

  • The capability cue, every role, ≈32 tokens.
  • Register cues: Shared, then Human (coordinator) or Agent (job).
  • The Failure cue, if the last turn stopped on an error. The Wake cue, if the prompt starts “Limen job ”.
  • Job: ticket path, vision and board pointers.
  • “Last turn edited <path>”, after a write or edit that got a reminder.
  • Coordinator: guidance drift and board size (> 120 lines).
  • Coordinator: on every human turn or idle wake. Job: once, with the task.

Tool result reminders (2)

  • Write or edit under spec/: the register's Specs cue.
  • Write or edit of a non-.md file: styleguide headings.
  • Bash with limen spawn, git merge, or a ticket into spec/features/planned/: vision headings.
  • Every other tool result: nothing. A job makes hundreds of calls; the text would sit inside data the model parses, and identical repeats turn into noise.
  • Group members only: group-peer.ts adds peer progress.

Steer (3) and wake (4)

  • Steer: limen steer writes steer/inbox; the job gets it between tool calls.
  • A job ends by the finish tool or engine exit. A finish ping goes to the webhook, queued and retried.
  • hook/wake.ts sweeps .limen/jobs and sends “Limen job …”. An idle coordinator starts a new turn and gets the note; a busy one queues it as a follow-up.

Not in a job's system prompt

Shop manual, vision, board digest. The hidden note points to the files instead.
